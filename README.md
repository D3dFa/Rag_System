# Локальная RAG-система по DM2024.pdf

Приложение отвечает на вопросы по выбранной главе учебника и содержит режим тренажера. LLM не используется: ответы выбираются из предложений учебника с помощью локального полнотекстового поиска BM25.

## Что извлечено

- PDF: `DM2024.pdf`
- Количество глав в актуальном учебнике: 10
- Выбранная глава: `1. Множества и отношения`
- Диапазон выбранной главы: PDF-страницы 58-316
- Индекс: `data/index.json`

Ключевые слова по главам берутся из дерева оглавления/онтологических разделов учебника: название главы и ее подразделы превращаются в список тем. Для выбранной главы текст очищается от подписи рисунков и эвристически найденных алгоритмических блоков; изображения не попадают в текстовый слой PDF.

## Локальный запуск

```powershell
py -3 -X utf8 app.py
```

Откройте `http://127.0.0.1:8000`.

## Пересборка индекса

```powershell
py -3 -X utf8 scripts\build_data.py
```

Индексатор работает на стандартной библиотеке Python: сам читает PDF-объекты, восстанавливает текст через `ToUnicode` CMap, режет главу на чанки и генерирует вопросы тренажера.

## Docker

```powershell
docker build -t dm-rag .
docker run --rm -p 8000:8000 dm-rag
```

Контейнер использует только `app.py`, `public/` и `data/index.json`; PDF не копируется в образ.
